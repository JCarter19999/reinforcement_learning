# reinforcement_learning

A personal reinforcement learning sandbox for building intuition from simple toy problems up to more advanced control and policy optimization tasks.

## Planned demos
- bandit
- gridworld
- frozen lake
- cartpole
- mountaincar
- pendulum

## Goals
- understand RL fundamentals without relying on black-box implementations
- compare algorithms across simple environments
- build a structured progression from tabular methods to policy optimization
- track experiments with TensorBoard

## Structure
- `bandit/` - multi-armed bandit experiments
- `gridworld/` - tabular value and policy learning
- `frozen_lake/` - sparse reward and stochastic transitions
- `cartpole/` - first function approximation / control task
- `mountaincar/` - delayed reward exploration challenge
- `pendulum/` - simple continuous control
- `shared/` - reusable utilities
- `logs/` - experiment logs and TensorBoard outputs
- `notes/` - theory notes and summaries
